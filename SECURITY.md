# Security

A theme file here is colours and CSS. It holds no script, and T3 Code does not let a theme's CSS load anything from a
network. The parts of this repository that run are the install script (`install.sh`), the checks in `scripts/`, and
the Studio in `studio/`, which runs in your browser or in Node and sends nothing anywhere.

If you find a way any of these could harm someone who uses them, please report it privately: on the repository's
**Security** tab, choose **Report a vulnerability**. Please do not open a public issue for it.

Problems in T3 Code itself belong with [its own repository](https://github.com/pingdotgg/t3code).
